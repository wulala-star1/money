# 小猪存钱 · 把每个心愿存成生活 🐷✨

一款温润治愈的日系手账生活风存钱与心愿管理应用。把大大的渴望拆解为每天微小的坚持，今天省下一杯奶茶、少点一次外卖，存钱罐里的金币就又多了一枚。

## ✨ 核心亮点

- **温馨治愈手账美学**：告别冷冰冰的 AI 模板，采用奶油米白纸质感、焦糖暖橙主色，搭配细腻的手绘生活插画。
- **全系列生活心愿画廊**：收录智能轿跑、森林小木屋、Switch 游戏机、海岛旅行、生活微单、猫咪基金等丰富的心愿插画。
- **PWA 手机原生全屏体验**：支持安装到 iPhone 和 Android 手机主屏幕，全屏沉浸运行，无浏览器地址栏。
- **全自动无感热更新**：接入 Service Worker，服务器更新代码后，手机端自动静默同步最新版本。
- **纯本地安全隐私**：数据保存在本地设备存储中，不上传第三方服务器，安全无忧。

## 📱 手机端安装为 App 教程

### 苹果 iPhone (iOS Safari)
1. 在 iPhone 自带的 **Safari 浏览器** 中打开你的部署网址；
2. 点击底部工具栏正中间的 **「分享」** 按钮（带箭头的方框）；
3. 在弹出菜单中向下滑动，点击 **「添加到主屏幕」**；
4. 点击右上角 **「添加」**，手机桌面上即会生成专属的「小猪存钱」App 图标；
5. 从桌面点开即可全屏运行，如同原生应用！

### 安卓手机 (Android Chrome / Edge / 自带浏览器)
1. 在手机浏览器中打开部署网址；
2. 浏览器底部会弹出 **「将小猪存钱添加到主屏幕」**（或点击右上角菜单 `⋮` -> 点击 **「安装应用」** 或 **「添加到主屏幕」**）；
3. 确认添加后，桌面即生成独立 App，支持离线启动和即时热更新。

## 🚀 免费一键上架与部署指南

### 推荐方式：Vercel 一键上线（最推荐，全自动部署与更新）
1. 打开 [vercel.com](https://vercel.com/) 并使用 GitHub 账号登录；
2. 点击 **「Add New...」** -> **「Project」**；
3. 选择你的 GitHub 仓库（例如 `piggy-saving`）；
4. Framework Preset 选择 **Other**，Root Directory 保持默认，点击 **Deploy**；
5. 约 10 秒后即可获得全球访问的免费专属 HTTPS 域名（例如 `xiaozhu-saving.vercel.app`）！
6. **后续更新**：只要你往 GitHub 仓库提交代码，Vercel 会自动重新部署，所有用户手机端全自动热更新！
